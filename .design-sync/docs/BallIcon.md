# BallIcon

A football. Goals in the match timeline and scorer lines under the scorebug (`size={12}`), the Goal button.

A 16×16 line icon (1.5px stroke) that takes `currentColor` and sits on the text baseline, so it can go inline in a label. Pass `size` for larger use and `title` when the icon is the only label.

```jsx
<div className="num" style={{ fontSize: 12, color: footballTheme.muted }}><BallIcon size={12} /> Rahul 23', 67'</div>
```
